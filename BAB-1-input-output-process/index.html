Bab 1: Input & Output

Belajar Java: Input & Output

Materi Dasar dan Interaktif

Menampilkan Output di Java

Di Java, kita menggunakan object System.out untuk mencetak teks ke console. Berikut adalah penjelasan detail dari tiga metode utama yang sering digunakan:

1. System.out.print()

Mencetak teks tanpa berpindah baris. Kursor akan tetap berada tepat di sebelah akhir teks yang baru saja dicetak.

Contoh Kode: 
System.out.print("Nama: ");
System.out.print("Ficky");
Contoh Hasil: 
Nama: Ficky

2. System.out.println()

Mencetak teks lalu menambahkan baris baru (new line) di akhir. Teks yang dicetak setelahnya akan otomatis berada di baris bawah.

Contoh Kode: 
System.out.println("Ini baris pertama.");
System.out.println("Ini baris kedua.");
Contoh Hasil: 
Ini baris pertama.
Ini baris kedua.

3. System.out.printf()

Singkatan dari print format. Metode ini digunakan untuk mencetak teks dengan menyisipkan nilai variabel menggunakan Argumen Format (Format Specifier).

Argumen Format Dasar:

  • %s : Untuk String (teks).
  • %d : Untuk bilangan bulat / decimal integer (int, short, long).
  • %f : Untuk bilangan pecahan / floating-point (float, double).
  • %c : Untuk karakter tunggal (char).
  • %n atau \n : Untuk membuat baris baru.

Penggunaan Flag:

Flag disisipkan antara tanda % dan huruf argumen format untuk mengatur tampilan secara spesifik (seperti pembulatan atau spasi). Beberapa contoh flag:

  • Membatasi Desimal (%.2f): Menampilkan hanya 2 angka di belakang koma (akan otomatis dibulatkan).
  • Padding Nol (%03d): Menambahkan angka 0 di depan jika digit kurang dari 3. Misal angka 5 akan dicetak 005.
  • Mengatur Lebar/Spasi (%10s): Memberikan ruang sebanyak minimal 10 karakter (rata kanan).
Contoh Kode: 
String nama = "Andi";
int umur = 21;
double ipk = 3.8765;
int antrian = 7;

// Menggunakan %s dan %d
System.out.printf("Mahasiswa bernama %s berusia %d tahun.%n", nama, umur);

// Menggunakan flag pembatasan desimal (%.2f)
System.out.printf("IPK saat ini: %.2f%n", ipk);

// Menggunakan flag padding nol (%03d)
System.out.printf("Nomor antrian Anda: %03d%n", antrian);
Contoh Hasil: 
Mahasiswa bernama Andi berusia 21 tahun.
IPK saat ini: 3.88
Nomor antrian Anda: 007

Mengambil Input dari User

Untuk menerima data dari pengguna melalui console, Java menyediakan beberapa kelas. Dua yang paling populer adalah Scanner dan BufferedReader.

1. Menggunakan Scanner

Scanner adalah cara paling populer dan mudah digunakan karena secara otomatis dapat mem-parsing (menerjemahkan) tipe data primitif langsung dari inputan. Untuk menggunakannya, kita wajib menambahkan import java.util.Scanner; di awal file.

Method yang Sering Digunakan pada Scanner:

  • next() : Digunakan untuk membaca String sebanyak satu kata saja. Input akan terpotong jika ada spasi.
  • nextLine() : Digunakan untuk membaca String satu baris penuh, termasuk spasi di dalamnya, hingga user menekan tombol Enter.
  • nextInt() : Digunakan untuk membaca input berupa angka bulat (tipe data int).
  • nextDouble() : Digunakan untuk membaca input berupa angka desimal/pecahan (tipe data double).
  • nextBoolean() : Digunakan untuk membaca input tipe data boolean (true atau false).
Contoh Kode: 
import java.util.Scanner;

public class InputScanner {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Masukkan nama depan Anda (1 kata): ");
        String namaDepan = scanner.next();
        
        // Membersihkan karakter "Enter" yang tersisa
        scanner.nextLine(); 
        
        System.out.print("Masukkan hobi Anda (bisa banyak kata): ");
        String hobi = scanner.nextLine();
        
        System.out.print("Masukkan umur Anda: ");
        int umur = scanner.nextInt();
        
        System.out.println("\n--- Hasil ---");
        System.out.println("Nama Depan : " + namaDepan);
        System.out.println("Hobi       : " + hobi);
        System.out.println("Umur       : " + umur + " tahun");
        
        scanner.close();
    }
}
Contoh Hasil: 
Masukkan nama depan Anda (1 kata): Budi
Masukkan hobi Anda (bisa banyak kata): Bermain Sepak Bola
Masukkan umur Anda: 20

--- Hasil ---
Nama Depan : Budi
Hobi       : Bermain Sepak Bola
Umur       : 20 tahun
